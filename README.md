# Personal Finance API

A production-grade REST API for managing personal finances, tracking income and expenses, organizing transactions, and monitoring budgets.

## Overview

Personal Finance API is a backend application designed to help users manage their financial activities through a secure and structured API.

The project focuses on building a scalable backend with proper authentication, validation, database management, error handling, and security practices.

## Tech Stack

- **Language:** TypeScript
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL
- **ORM:** Prisma

## Core Features

- User registration and authentication
- Secure password hashing
- JWT-based authentication
- Income and expense management
- Transaction categories
- Budget management
- Financial summaries and reports
- Input validation and error handling
- Pagination and file uploads
